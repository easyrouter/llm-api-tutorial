# 安装 Codex CLI / Claude Code

两个工具都通过 npm 全局安装，命令只有一行：

```
npm install -g @openai/codex
npm install -g @anthropic-ai/claude-code
```

你只需要安装自己会用到的那个；两个都用就都装。

## 工具会怎么做

1. 先向你展示将要执行的完整命令（包括使用哪个 npm 源），你点"确认"后才开始。
2. 如果官方源较慢或不可达，会自动切换到国内镜像（npmmirror），命令里会明确写出 `--registry`。
3. 安装过程的输出会实时显示在窗口里，可以随时取消。
4. 装完后自动重新检查版本。

整个过程**不需要管理员权限**：npm 的全局目录默认在你的用户目录下。如果检测到全局目录不可写，工具会提示你切换到用户级前缀，而不是让你用 sudo 或"以管理员身份运行"。

## 安装成功的标志

安装结束后，工具会在一个全新的会话里运行 `codex --version` 或 `claude --version`。能看到版本号即为成功。

如果工具说"已安装，但当前 PATH 未生效"，不是安装出错，而是已经打开的终端还没有加载新的 PATH：把**所有**终端窗口（包括编辑器里的内置终端）关掉再打开就好了。详见"生效与验证"和故障 E。

## 常见问题

**安装很慢或者卡住**
点"取消"，重新点"安装"，工具会重新探测网络并可能切换到镜像。也可以先在"环境检查"里看网络那一项。

**提示 EACCES / 权限被拒绝**
说明 npm 全局目录在系统目录里。工具会给出把 npm 前缀改到用户目录的命令，确认后执行；之后需要重新安装一次。

**公司电脑不允许安装软件**
npm 全局安装只是把文件复制到你的用户目录，通常不受软件安装策略限制。如果安全软件拦截了 `node.exe`，请联系 IT 把它加入白名单。

**想升级到最新版本**
再执行一次同样的安装命令即可，npm 会覆盖旧版本。
