# 安装 Node.js

Codex CLI 和 Claude Code 都是通过 npm 发布的命令行工具，而 npm 随 Node.js 一起安装。所以 Node.js 是第一块积木：版本需要 **18 或更高**，推荐直接安装当前的 LTS（长期支持）版本。

## 工具会怎么帮你

1. 检测你的网络到官方站点和国内镜像哪个更快，自动选一个下载页面。
2. 打开下载页面（或直接下载安装包），并在你安装完成后提供"重新检查"按钮。
3. Node.js 的安装程序本身由官方提供，工具不会替它做任何静默安装。

## Windows

1. 下载 **Windows Installer (.msi)**，选择与你系统匹配的 x64 或 ARM64 版本。
2. 双击运行，一路"下一步"即可；默认会勾选把 Node.js 加入 PATH，请保持勾选。
3. 如果安装程序提示需要管理员权限而你没有，可以改用 **.zip 便携版**：解压到你自己的目录（例如 `C:\Users\你的用户名\nodejs`），然后在"系统属性 → 环境变量 → 用户变量 → Path"里新增这个目录。
4. **关闭所有已打开的终端窗口**，回到工具点"重新检查"。

## macOS

1. 下载 **macOS Installer (.pkg)**，Apple 芯片选 ARM64，Intel 芯片选 x64（不确定时点左上角苹果菜单 →"关于本机"查看）。
2. 双击安装，按提示完成。
3. 如果你已经安装了 Homebrew，也可以在终端执行 `brew install node`。
4. 关闭所有终端窗口后回到工具点"重新检查"。

## 已经装了 Node.js 但版本太旧？

直接安装新版本即可，安装程序会覆盖旧版本。如果你使用 nvm / fnm / volta 之类的版本管理器，请用它们切换到 18 以上的版本，并确认默认版本也已切换（例如 `nvm alias default 22`）。

## 校验是否成功

打开一个**新的**终端窗口，输入：

```
node -v
npm -v
```

两条命令都能显示版本号（`v18` 或更高）就说明成功了。
