# 欢迎使用 SeedRouter 接入引导

这个小工具的任务只有一件事：带你从"什么都没装"走到"Codex CLI 或 Claude Code 能通过服务网关正常工作"，中途不需要你查资料、猜命令；需要管理员权限的只有极少数步骤，而且按钮上会写明。

## 你会经历的六个步骤

1. **环境检查** — 自动查看系统版本、Node.js、命令行工具、CC Switch、Codex 客户端、环境变量和网络是否就绪。缺什么、哪里不对，都有一键按钮（安装 Node.js、修复 PATH、清理环境变量、安装 Codex 客户端）。
2. **安装** — 只安装缺失的部分。每一条要执行的命令都会先显示出来，你确认后才会运行。
3. **配置** — 打开 CC Switch，把服务网关添加为供应商（有 ChatGPT 账号的 Codex 用户直接用"OpenAI 官方"预设并登录）。需要填写的值（地址、协议、名称）工具会直接给出，点一下即可复制；API Key 由你自己粘贴；Codex 的 `config.toml` 模板可一键应用（带备份）。
4. **验证** — 工具在一个全新的会话里运行命令行工具，并可选地向网关发一条最小请求，直接告诉你成功还是失败。
5. **诊断** — 失败时自动对照故障 A–G 给出结论和修复步骤，而不是丢给你一串错误码。
6. **完成** — 之后你可以随时回来重新检查。

## 这个工具**不会**做的事

- 不会修改 `~/.claude/`、`~/.cc-switch/` 里的任何文件；在 `~/.codex/` 里只会写 `config.toml` 一个文件，而且只在你点"一键应用"之后、先备份。供应商配置始终由你在 CC Switch 中完成，工具只负责引导和核对。
- 不会悄悄修改你的环境变量或 PATH。"一键清理"和"一键修复 PATH"都先把将要改动的内容完整显示出来，你确认后才执行，改过的文件有备份；系统级（所有用户）PATH 从不改动。
- 不会保存、记录或上传你的 API Key。连通性测试时 Key 只在内存中停留一次请求的时间。
- 不会在未经确认的情况下运行任何命令，也不会静默申请管理员权限——需要管理员权限的按钮会写明，提示框由系统 / 安装程序弹出。详见"一键操作说明"。

## 需要准备什么

- 一台 Windows 10（2004 及以上）或 macOS 12 及以上的电脑，能访问办公网络。
- 你的 API Key。如果还没有，请按公司流程申请；工具无法替你申请。
- 大约 10 分钟。

## 遇到问题怎么办

先看右侧帮助面板里对应步骤的说明；验证失败时工具会自动打开诊断面板。若仍无法解决，点"导出诊断报告"，把生成的文件发给 IT 支持——报告中的密钥和敏感信息已自动脱敏。
