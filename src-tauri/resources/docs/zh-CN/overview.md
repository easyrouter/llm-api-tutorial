# 欢迎使用 Codex 接入引导

这个小工具的任务只有一件事：带你从"什么都没装"走到"Codex CLI 或 Claude Code 能通过服务网关正常工作"，中途不需要你查资料、猜命令，也不需要管理员权限。

## 你会经历的六个步骤

1. **环境检查** — 自动查看系统版本、Node.js、命令行工具、CC Switch、环境变量和网络是否就绪。
2. **安装** — 只安装缺失的部分。每一条要执行的命令都会先显示出来，你确认后才会运行。
3. **配置** — 打开 CC Switch，把服务网关添加为供应商。需要填写的值（地址、协议、名称）工具会直接给出，点一下即可复制；API Key 由你自己粘贴。
4. **验证** — 工具在一个全新的会话里运行命令行工具，并可选地向网关发一条最小请求，直接告诉你成功还是失败。
5. **诊断** — 失败时自动对照故障 A–G 给出结论和修复步骤，而不是丢给你一串错误码。
6. **完成** — 之后你可以随时回来重新检查。

## 这个工具**不会**做的事

- 不会修改 `~/.codex/`、`~/.claude/`、`~/.cc-switch/` 里的任何文件——配置始终由你在 CC Switch 中完成，工具只负责引导和核对。
- 不会修改你的环境变量。发现冲突时会告诉你在哪里、怎么改。
- 不会保存、记录或上传你的 API Key。连通性测试时 Key 只在内存中停留一次请求的时间。
- 不会在未经确认的情况下运行任何命令，也不会静默申请管理员权限。

## 需要准备什么

- 一台 Windows 10（2004 及以上）或 macOS 12 及以上的电脑，能访问办公网络。
- 你的 API Key。如果还没有，请按公司流程申请；工具无法替你申请。
- 大约 10 分钟。

## 遇到问题怎么办

先看右侧帮助面板里对应步骤的说明；验证失败时工具会自动打开诊断面板。若仍无法解决，点"导出诊断报告"，把生成的文件发给 IT 支持——报告中的密钥和敏感信息已自动脱敏。
