# 安装 CC Switch

CC Switch 是一个开源的图形界面小工具（MIT 协议），用来统一管理 Codex CLI 和 Claude Code 的供应商配置：你在它的界面里填一次服务网关，它负责把配置写到各工具正确的位置，之后还可以在多个供应商之间一键切换。因为公司要求支持多供应商切换，所以它是**必装项**。

## 工具会怎么帮你

1. 从 CC Switch 的官方发布渠道获取最新版本，按你的系统和芯片选择对应安装包。
2. 通过 https 下载到本工具的缓存目录；如果发布页提供了 SHA-256 校验值，会先校验再交给你。
3. 下载完成后点"打开安装包"，剩下的安装步骤由 CC Switch 的安装程序完成。

请只从工具提供的链接或公司内网分发点下载，不要在搜索引擎里随便点结果——曾经出现过仿冒的下载站。

## Windows

1. 下载 `.exe` 安装包（NSIS）或便携版。
2. 双击运行。如果弹出蓝色的 **"Windows 已保护你的电脑"** 提示，点 **"更多信息" → "仍要运行"**（见故障 G）。
3. 安装完成后启动一次 CC Switch，确认能正常打开。

## macOS

1. 下载 `.dmg`，打开后把 CC Switch 拖进"应用程序"文件夹。
2. 第一次打开如果提示 **"无法打开，因为无法验证开发者"** 或 **"已损坏"**：打开 **系统设置 → 隐私与安全性**，在页面底部找到被拦截的提示，点 **"仍要打开"**。如果没有这个按钮，在终端执行：

   ```
   xattr -d com.apple.quarantine /Applications/CC\ Switch.app
   ```

   然后再打开一次（见故障 G）。

## 装好之后

回到工具点"重新检查"，CC Switch 一项变为"通过"即可进入下一步"配置"。配置时你会在 CC Switch 的界面里操作，本工具会在旁边给出每一步要填的值。
