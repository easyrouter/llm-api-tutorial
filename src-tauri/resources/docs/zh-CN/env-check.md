# 环境检查

进入向导后检查会自动开始，全部检查通常在几秒内完成。每一项只有三种结果：

- **通过**：这一项没问题，不用管它。
- **警告**：可以继续，但后面可能会遇到麻烦；建议按提示处理。
- **阻断**：不解决就无法继续。每个阻断项旁边都有"修复"或"查看说明"按钮。

不少修复按钮现在是**一键操作**：一键安装 Node.js、一键修复 PATH、一键清理环境变量、安装 Codex 客户端。每个按钮都会先显示将要执行的内容，需要管理员权限的会在按钮上写明。每个按钮背后到底做了什么，见"一键操作说明"（`one-click`）。

## 检查了什么

| 项目                    | 看什么                                                         | 常见结果                         |
| ----------------------- | -------------------------------------------------------------- | -------------------------------- |
| 操作系统                | Windows 版本 / macOS 版本、架构                                | 版本过旧会阻断                   |
| Node.js                 | 是否安装、版本是否 ≥ 18                                        | 未安装或过旧 → 去"安装"步骤      |
| npm                     | 是否随 Node.js 一起可用                                        | 一般随 Node.js 通过              |
| Codex CLI / Claude Code | `codex --version` / `claude --version` 能否执行                | 区分"没装"和"装了但 PATH 没生效" |
| CC Switch               | 是否已安装                                                     | 未安装 → 去"安装"步骤            |
| Codex 客户端            | ChatGPT / Codex 桌面应用是否已安装（可选项）                   | 未安装 → 警告，可一键安装        |
| 环境变量                | 是否存在 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、`ANTHROPIC_*` 等 | 存在时警告，可一键清理（故障 D） |
| 网络                    | npm 源、服务网关、GitHub 是否可达                              | 不可达时提示切换镜像或检查代理   |

## 几个容易误解的地方

**"装了但 PATH 没生效"是什么意思？**
工具刚装好时，已经打开的终端窗口并不知道新命令在哪里。这不是安装失败，只需要把所有终端窗口关掉重开（详见"生效与验证"）。如果重开之后仍然找不到，说明命令所在目录确实不在 PATH 里——点"一键修复 PATH"，工具会把 Node.js 目录或 npm 全局目录加进你的用户 PATH（不需要管理员权限）。同样的按钮也用于"Codex CLI 已找到但无法运行：`'"node"' 不是内部或外部命令`"。

**为什么环境变量会被标为警告？**
如果系统里设置了 `OPENAI_API_KEY` 或 `OPENAI_BASE_URL` 这类变量，命令行工具会优先使用它们，从而绕过你在 CC Switch 中的配置——表现为"配了但没效果"或"401 认证失败"。工具会标出每个变量来自哪里（注册表、哪个文件的第几行），并提供"一键清理"：确认框里会显示每个变量的**完整值**，你确认后才删除，改过的文件都有备份（见故障 D 和"一键操作说明"）。

**网络检查失败一定有问题吗？**
不一定。它只测试"能不能连上"，不测试权限。如果办公网络需要代理，请先确认代理设置正确；npm 源不可达时，安装步骤会自动切换到镜像。

**Codex 客户端是必须的吗？**
不是。Codex CLI 在命令行里工作，不依赖桌面客户端。但桌面客户端（现在包含在 ChatGPT 桌面应用里）对非开发者更友好，所以这一项是"推荐"：Windows 可以从 Microsoft Store 安装或用离线安装包，Store 提示"地区不可用"时有一个按钮直接打开 Windows 区域设置；macOS 下载 DMG 安装。

## 下一步

处理完所有阻断项后点"下一步"。你也可以随时点"重新检查"刷新结果，或者点单项旁边的"重跑"只重新检查那一项。
